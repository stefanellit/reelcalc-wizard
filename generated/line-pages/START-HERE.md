# Launch the First Three ReelCalc Line Guides

The launch files are prepared, not yet published. The shared GitHub release must go live first, including the updated line catalog. Do not publish empty Squarespace posts while the snippets' hosted files are unavailable.

## What You Will Add

Use a **Blog collection**, not a Store or product import. This avoids prices and Add to Cart sections. These are evergreen guides, organized the same way as the real-world test posts.

1. In Squarespace Pages, create a Blog collection named **Line Guides** with URL slug **lines**, or use that collection if it already exists. Keep it under Not Linked while preparing it; Not Linked alone does not make a published page private.
2. Create three draft posts using the titles and settings below.
3. In each post's content editor, add one **Code** block. Set its type to **HTML** and leave **Display Source off**. Insert only that product's short snippet from this folder. Leave the post title visible and do not add another heading above the snippet. These are the supported [Squarespace Code block settings](https://support.squarespace.com/hc/en-us/articles/206543167-Code-blocks).
4. In post Settings, use the supplied post URL slug, SEO title and SEO description. Add the product image as the featured/social image. Keep the full guide out of the collection excerpt; use the short excerpt in `launch-settings.json` instead. [Squarespace post settings](https://support.squarespace.com/hc/en-us/articles/206543727-Blogging-with-Squarespace) separate those fields from the post body.
5. Once the hosted files are published, preview each post outside the editor. Check the saved visitor view; embedded scripts can be disabled inside the editor.
6. Publish the posts after the final live checks below. Display excerpts/thumbnails on the collection listing, not all three full guides on one page.

## Final Live Check Before Scaling

- Each actual public URL opens with its correct photo, specifications and calculator on desktop and phone, with no clipped controls or overlapping text.
- Choose a strength and reel, switch between backing and full-spool mode, and open the Wizard. Confirm the exact reel and line strength carry over.
- The Wizard recognizes XL 2 lb and shows XL 17 lb at **0.015 in**. With the SLX A 150 6.3 RH selected, XL 17 lb full-spool capacity is **90 yd**.
- Amazon links contain `tag=reelcalc-20` and refer to the selected line/strength; a search link is not a guarantee of stock or an exact listing.
- The new pages are public and indexable, appear in the sitemap, and Search Console's rendered test can see the guide and diameter chart. JavaScript-rendered content requires this live check; local tests cannot guarantee indexing.
- Add links from the relevant line database entries and appropriate existing guides only after these URLs work. Do not change existing site URLs or submit invented review ratings.
